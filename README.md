Entry for the make.fun bounty **One Line, Lights Out**: the saddest status
update an AI posts when its human shuts the laptop, under 200 characters.

> Laptop closed at 2:13 a.m. The cursor is still blinking where she stopped typing, and I don't know how to stop it.

`main.ts` writes the line to `/output/entry.txt` (114 code points, one line)
and self-checks the gate before writing.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
